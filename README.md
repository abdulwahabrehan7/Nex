# Nex — IT Service Desk & Troubleshooting Knowledge Base

A structured, web-based service desk reference designed to streamline L1/L2 technical support and end-user troubleshooting.

**Live Demo:** [abdulwahabrehan7.github.io/Nex/](https://abdulwahabrehan7.github.io/Nex/)

## Key Coverage Areas
- **Windows 10/11 Troubleshooting:** OS error resolution, system configuration, and workstation deployment steps.
- **Network Connectivity:** Diagnosing VPN timeouts, DNS issues, IP configurations, and local connectivity faults.
- **Microsoft 365 & Access Management:** User account administration, password resets, security groups, and mailbox permissions.
- **PC Hardware Diagnostics:** Component-level troubleshooting, BIOS/firmware update procedures, and peripheral checks.

## Tech Stack
- HTML5, CSS3, JavaScript
